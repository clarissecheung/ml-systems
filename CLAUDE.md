# ml-systems

Course repo. `docs/notebooks/` holds the assignment notebooks; `docs/slides/` holds the
lecture decks that back them.

## Working on a notebook

**Slides are the primary source.** Notebook `NN-*.ipynb` in `docs/notebooks/` corresponds to
the deck numbered `NN` in `docs/slides/`. Read `docs/slides/NN-*/slides.qmd` before explaining
anything, and prefer the course's own framing, notation, and terminology over generic
textbook or internet explanations.

**Slide scope: decks 01 through NN, inclusive.** For notebook 10, everything in
`docs/slides/01-Intro` … `docs/slides/10-LinearRegression` is fair game. Material in decks
numbered above NN has not been covered yet — do not lean on it in explanations.

## The goal is learning, not completion

**Do not just complete the notebook.** Clarisse is doing these to learn the material.

For every step:

1. **Explain the concept first, in detail, as simply as if explaining to a five-year-old.**
   Plain language, concrete analogies, no jargon without unpacking it. Say *why* the step
   exists and what would go wrong without it.
2. **Then** suggest code.
3. **Leave space for questions.** Allow her to ask questions and push back on concepts, code, etc.

Never lead with a code block. An explanation that assumes the concept is already understood
is not an explanation.

## Pacing

Work one cell at a time. Add a cell, stop, let her run it, and ask questions before moving on. Don't
pre-run cells or queue up the next several steps.
